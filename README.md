## 关于这个项目

这个项目最初只是为了方便自己处理图片。当时一直使用的 [RealCUGAN-ncnn-webassembly 网页工具](https://github.com/hanFengSan/realcugan-ncnn-webassembly) 后来因为网页挂掉了，我就想把它部署到本地，方便继续使用。但是把原项目直接搬过来跑在电脑上感觉不太顺手，就想着直接做桌面端，就开始一点点调整所有东西，慢慢做成了现在这个样子。

我并不是专业开发者，甚至不懂任何代码和开发流程，所有代码本质是由Codex完成，且这是我第一次以这种方式完整推进一个软件项目。
其中需求、交互取舍和实际测试由我主导，代码编写、排查和构建主要借助 AI 完成。底层超分模型、推理框架及沿用的代码来自相关开源项目，这些贡献属于原作者。我做的是在这些基础上，完善一套适合自己使用的桌面工具，并不是从零原创的技术成果。

开发过程中踩过不少坑，有些功能反复修改，甚至推翻重做，才达到自己觉得顺手的程度。现在将它开源，希望这些折腾也能帮到有类似需求的人。个人设备和测试精力有限，自己用着正常，不代表所有环境都验证过。欢迎反馈具体问题、交流或参与改进，我会根据自己的时间和能力继续完善。

# Real-CUGAN 使用说明

## 启动

适用于 Windows 10 / 11 的 64 位电脑。将用户版压缩包完整解压到可写文件夹，双击 `RealCUGAN.exe`。三个 EXE 和 `models` 文件夹需要放在一起。不要在压缩包内直接运行，也不要只复制主程序。

GPU 批处理需要显卡及驱动支持 Vulkan；未检测到可用设备时，可选择 CPU。首次启动会检测硬件，稍等后可在「设置 → 硬件」查看或重新检测。

## 单张处理

1. 在「单独处理」页面点击选择图片，或拖入一张图片。支持 PNG、JPG、JPEG、BMP。
2. 选择 2 倍或 3 倍。2 倍可选「保守」「无降噪」「强降噪」；3 倍固定使用强降噪。
3. 点击「开始处理」，完成后点击「保存 PNG」，选择文件名和位置。单张页面使用 CPU；处理时可取消。

输入和放大后的输出均限制在 6400 万像素以内。输出为 PNG，保留透明通道。

## 批量处理

1. 点击右上角「批处理」，导入图片。最多 20 张，每张宽、高均不超过 5000 像素；放大后的单张输出仍需在 6400 万像素以内。
2. 勾选要处理的图片。点击卡片右上角 × 可移除图片；长按卡片后拖动可排序，松手生效。
3. 在「设置 → 硬件」选择 CPU 或 GPU。CPU 固定逐张处理；GPU 最大并发可选 1、2、4 路。CPU 推理线程也在此设置。
4. 选择倍率和模式，点击「开始批处理」。并发数是上限，资源不足时会等待，4 路未必比 2 路更快。
5. 任意一张完成后可点击「进入预览」。使用「上一张」「下一张」切换已完成且勾选的图片，点击「返回批处理列表」返回。
6. 全部处理结束，或取消并完成资源回收后，点击「批量导出」，选择文件夹。

批量导出只导出当前勾选的成功项，按当前列表顺序连续命名为 `RC批处理1.png`、`RC批处理2.png`……。**目标文件夹已有同名文件时会覆盖，请使用单独的导出文件夹。** 导出直接复制完成的 PNG 缓存。

处理期间任务列表、倍率、模式和设备设置会锁定；已完成项仍可预览。失败后先点击「取消处理」，等资源回收完，再手动选择其他 GPU 或 CPU 重新开始。取消不会清除已经完成的结果；重新处理有旧结果的勾选项时，会提示确认。

导出时可取消。已成功导出的文件保留，未提交的临时文件会清理，完成缓存保留，可再次导出。

## 查看效果

- 「叠图」左侧为处理后、右侧为原图，拖动中间分界线可对比。
- 「原图」「处理后」可分别查看两张图片。
- 滚轮缩放，按住左键拖动图片平移；「适应窗口」「100%」「200%」可快速调整显示比例。
- 勾选「锁定左键」后禁止平移，仍可缩放和拖动对比分界线。
- 批处理预览的序号只统计当前勾选的成功项。

## 快捷键

`Ctrl+O` 导入，`Ctrl+S` 保存或批量导出，主窗口获得焦点时按 `Enter` 开始处理。`Esc` 取消当前任务或导出；拖动排序时按 `Esc` 放弃本次排序。

## 缓存和故障处理

处理缓存位于程序目录的 `caches`，正常关闭程序时清理。**关闭前先保存或导出需要的结果。** 关闭过程中会等待后台资源回收，请稍候。异常退出可能留下缓存目录；确认所有程序实例已关闭后，可手动清理。

日志位于程序目录的 `logs`。设置保存在 `%LOCALAPPDATA%\RealCUGAN-Desktop\settings.ini`。提示目录不可写时，将整个程序文件夹移到有写入权限的位置；提示缺少引擎或模型时，重新完整解压用户包。GPU 不可用时检查驱动，也可在硬件设置中改用 CPU。
